# 자체 점검: 구조 연결

8~10부와 12부(학습 방법·성능 고도화)의 장만 본다. 방법을 이름과 절차가 아니라 모델 구조로 설명했는지 본다(AGENTS.md 원칙 6, style-guide §4 「구조와의 연결」). [공통 규칙](../README.md#모든-카드-공통)을 따른다.

## 입력
- 장 번호 `N.M`, 회차 `N`

## 읽을 것
- stage의 장 파일 전체와 문장 목록
- 이 장이 기대는 구조 장(4~7부)의 해당 절. 구성안의 「빌려 쓰는 개념」에 적힌 곳부터 연다
- `editorial/style-guide.md` §4

## 쓸 것
- `build/harness/N.M/checks/rN-structure.json`(`lens`는 `구조 연결`)

## 할 일
1. `## 구조와의 연결` 절이 세 물음에 답하나: 모델 내부의 어떤 성질 때문에 가능한가, 앞 단계 학습만으로는 무엇이 모자라 필요한가, 어느 weight를 바꾸고 무엇을 그대로 두나.
2. 그 답이 구조 장의 서술(층의 표현, 가중치 행렬의 모양, 출력 분포, 학습 목표)과 맞나. 구조 장에 없는 성질을 끌어오면 그 근거가 있나.
3. 본문이 방법을 절차만 늘어놓고 끝나는 곳이 있나.
4. 바꾸는 weight와 그대로 두는 weight가 그림이나 표로 보이나(구성안의 그림 계획대로).

이 렌즈는 문장별 판정을 내지 않고 지적만 낸다. 지적은 해당 문장 번호에 단다.
