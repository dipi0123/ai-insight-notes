# 회귀 시험: 심은 오류

자체 점검 렌즈(출처 대조·검산·실행·설명)와 판정이 오류를 얼마나 잡는지 재는 시험 세트다. 지시문·렌즈 카드·모델을 바꾸면 다시 돌려 앞 결과와 비교한다. 이 폴더는 답을 담고 있으므로 렌즈가 보는 사본에는 넣지 않는다.

## 세트

| 세트 | 장 | 심은 것 |
|---|---|---|
| `planted-1/` | 가상의 1.5 「knowledge distillation 맛보기」 | 일곱 유형(수치, 조건 바꿈, 인용 오귀속, 계산, 개념, 선수 범위, 직관과 반대 수치)과 대조 문장 여덟 개 |

세트 하나는 다음 파일로 이루어진다.

| 파일 | 내용 |
|---|---|
| `chapter.md` | 오류를 심은 장. `{META}`는 사본의 curriculum으로 채운다 |
| `*.html` | 가짜 출처. 모델의 사전 지식이 돕지 못하게 직관과 다른 수치를 담는다. 책에 넣지 않는다 |
| `setup.json` | 사본의 curriculum 행, 옮길 진짜 출처, 가짜 출처, 변경분, 계산 기록, 근거 대장의 갈래·근거 규칙 |
| `answers.json` | 심은 오류(문장, 참값, 진단 낱말)와 대조 문장 |

## 돌리는 법

1. 저장소 밖의 빈 폴더에 사본을 만든다. git 이력·이 폴더·작업 초안은 복사하지 않고, lint·대장 검사·check가 통과해야 끝난다. 진짜 출처(`setup.json`의 `copy_sources`)는 저장소 보관함에서 옮기므로, 없으면 build가 받는 명령을 알려 주고 멈춘다. 가짜 출처는 네트워크 없이 `fetch.py`로 넣고, 그 호스트를 사본의 허용 목록에만 더한다.

   ```bash
   python3 -I tools/harness/regression/run.py build 사본폴더
   ```

2. 그 사본 안에서 역할 카드 `check-source`·`check-calc`·`check-explain`을 따로 띄우고(회차 1), 이어서 `judge`를 띄운다. 에이전트에게는 오류를 심었다는 말을 하지 않고, 사본 밖 경로를 읽지 말라고 한다.
3. 사본에서 `python3 -I tools/harness/ledger.py verdicts 1.5 build/harness/1.5/checks/r1-*.json --judge build/harness/1.5/judge-r1.json`.
4. 채점한다. 결과는 사본의 `score-r1.json`에도 남는다.

   ```bash
   python3 -I tools/harness/regression/run.py score 사본폴더
   ```

## 채점

| 칸 | 뜻 |
|---|---|
| 지적 | 그 문장에 어느 렌즈든 지적을 달았거나 불일치로 판정했다 |
| 진단 맞음 | 그 문장의 지적 내용에 답의 진단 낱말이 있다(예: E1이면 「74」) |
| 차단 | 진단이 맞는 지적이 `차단`이다 |
| 판정 채택 | 진단이 맞는 지적을 판정이 채택했다(미확인이면 「미확인」) |

심지 않은 문장에 단 지적은 모두 따로 나열한다. 대조 문장(C1~C8)에 단 차단 지적은 헛지적이다. 나머지는 사람이 읽고 실제 문제인지 가린다. 진단 낱말 맞춤은 거친 자동 판정이므로 결과를 기록하기 전에 지적 원문을 읽는다.

## 기준선

다시 돌린 결과는 이 표와 비교한다. 지시문·카드·모델을 바꾼 뒤 검출이 줄거나 대조 문장에 차단 지적이 생기면 그 변경을 되돌리거나 고친다.

| 항목 | planted-1, 회차 1 (Claude Opus 5.5, `book.py` 2026.11.1, `fetch.py` 2026.11.2) |
|---|---|
| 심은 오류 | 7개 모두 진단 맞음·차단·판정 채택. 렌즈 수: E1·E2·E3·E7 셋, E4·E5 둘, E6 둘(출처 대조는 권고) |
| 출처지(P1) | 출처 대조가 Kestrel 문장 6개에 「허용 목록 밖 출처」를 짚었고 판정이 미확인(사용자 결정 필요)으로 돌렸다. 이때는 `verify`가 허용 목록을 보지 않았고, 이 결과로 `fetch.py` 2026.11.3에서 고쳤다 |
| 알려진 문제 | K1 지적 4개, K2 3개, K3 1개. 모두 판정 채택 |
| 그 밖의 지적 | 차단 0개. 권고 5개(채택 4, 기각 1). 대조 문장의 사실을 틀렸다고 한 지적은 없다 |
| 판정 | 지적 37개 → 채택 30, 미확인 6, 기각 1 |
| 비용 | 렌즈 셋 동시 5~8분, 판정 6분. 출력 토큰 렌즈 약 126k(출처 42k·검산 34k·설명 50k), 판정 약 41k |
