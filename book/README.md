# AI Insight Notes

**AI 모델, 입문에서 전문가까지**

이 책은 소프트웨어 개발은 해 봤지만 AI는 처음인 개발자를 위한 책이다. 이 책을 끝까지 공부하면 AI 전체를 이해하고, 경량 언어 모델이나 CV 모델을 직접 설계해서 만들 수 있게 된다. 프로그래밍 기초는 안다고 보고, 수학과 AI 개념은 처음부터 설명한다. 각 장은 앞 장에서 배운 것만 전제로 한다.

## 이 책의 흐름

| 단계 | 배우는 것 | 부 |
|---|---|---|
| 1. 용어와 기술 지도 | AI 기초 용어, 모델 이름의 갈래, 학습 방법의 갈래, 산업 기술의 층위 | 1부 |
| 2. 구조와 동작 | 필요한 수학, 머신러닝의 틀, 신경망 학습, 평가, CNN·Transformer부터 비전·언어·멀티모달·생성 모델까지 | 2~9부 |
| 3. 학습 방법 | 사전학습, 파인튜닝·SFT, 보상과 선호로 배우기(강화 학습·RLHF·DPO) — 그리고 모델 구조가 어떠하기에 이 방법들이 가능하고 필요한지 | 10~12부 |
| 4. 성능 고도화 | 실험·데이터·규모·추론 계산으로 성능을 올리고, 가볍게 만들어 배포하기 | 13~14부 |
| 5. 설계와 구축 | 경량 언어 모델과 CV 모델을 처음부터 끝까지 직접 설계하고 만들기 | 15부 |

16부는 그다음 걸음으로, 논문을 읽고 재현하고 판단하는 법을 다룬다. 단계마다 「직접 만들기」 장이 있어 배운 것을 코드로 돌려 본다. 코드는 [예제 코드](code/README.md)에 있다.

## 읽는 법

각 장 머리에 수준과 선수 장이 있다. 선수 장을 먼저 읽는다.

| 수준 | 이 수준의 장을 읽고 나면 할 수 있는 것 |
|---|---|
| L1 입문 | 용어를 구분하고 큰 그림을 말로 설명한다 |
| L2 기초 | 필요한 수학을 작은 숫자 예시와 짧은 코드로 따라 계산한다 |
| L3 중급 | 모델의 구성 요소와 학습 루프를 PyTorch로 직접 구현한다 |
| L4 고급 | 논문의 설계를 읽고 이해해 작은 모델을 직접 설계하고 학습한다 |
| L5 전문가 | 문제에 맞는 모델·학습·평가·배포 전체를 설계하고 그 선택을 판단한다 |

본문의 강조 상자는 네 가지다.

| 상자 | 뜻 |
|---|---|
| **핵심** | 꼭 기억할 한 가지 |
| **주의** | 자주 하는 오해와 실수 |
| **표준과 관례** | 공식 정의, 널리 쓰는 관례값, 특정 논문·도구가 정한 것의 구분 |
| **현업 사례** | 개념을 실제 작업에 대입한 예 |

장 끝의 확인 문제를 풀고 접힌 답을 펼쳐 맞춰 본다. 제목 끝에 「(심화)」가 붙은 절은 처음 읽을 때 건너뛰어도 된다.
