# AI Insight Notes

**AI 모델, 입문에서 전문가까지**

이 책은 AI 모델을 처음 배우는 사람이 용어와 큰 그림에서 출발해 수학의 최소한, 신경망 학습, 평가, 비전·언어·멀티모달 모델, 사전학습 모델 활용, 학습 엔지니어링, 연구 판단까지 차례로 익히도록 엮었다. 각 장은 앞 장에서 배운 것만 전제로 한다.

## 읽는 법

각 장 머리에 수준과 선수 장이 있다. 선수 장을 먼저 읽는다.

| 수준 | 이 수준의 장을 읽고 나면 할 수 있는 것 |
|---|---|
| L1 입문 | 용어를 구분하고 큰 그림을 말로 설명한다 |
| L2 기초 | 개념을 작은 숫자 예시로 직접 계산한다 |
| L3 중급 | 모델 구조와 학습 과정을 코드 수준에서 설명한다 |
| L4 고급 | 논문을 읽고 설계 선택의 이유와 대가를 설명한다 |
| L5 전문가 | 문제에 맞는 모델·학습·평가를 설계하고 판단한다 |

본문의 강조 상자는 네 가지다.

| 상자 | 뜻 |
|---|---|
| **핵심** | 꼭 기억할 한 가지 |
| **주의** | 자주 하는 오해와 실수 |
| **표준과 관례** | 공식 정의, 널리 쓰는 관례값, 특정 논문·도구가 정한 것의 구분 |
| **현업 사례** | 개념을 실제 작업에 대입한 예 |

장 끝의 확인 문제를 풀고 접힌 답을 펼쳐 맞춰 본다. 제목 끝에 「(심화)」가 붙은 절은 처음 읽을 때 건너뛰어도 된다.

## 학습 경로

| 목표 | 읽는 순서 |
|---|---|
| 처음부터 차근차근 | 1부부터 12부까지 차례로 |
| 용어와 큰 그림만 | 1부 |
| 비전 모델 실무 | 1부 → 3부 → 4부 → 5.1~5.6 → 6.1·6.2·6.4~6.6 → 7부 → 10.1·10.6 → 11부 |
| LLM 활용 | 1부 → 3.1~3.3 → 6.4~6.7 → 8부 → 10부 |
| 논문을 읽고 판단하기 | 5부 → 12부. 모르는 개념은 선수 장으로 돌아간다 |
