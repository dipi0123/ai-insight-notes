- 책 고유의 분류: §1.3 예시 표(s-d70721~s-8129b4)와 §2.2 비교표(s-33e7c4~s-30b236). 특히 규칙과 수 읽기로 두는 체스 프로그램을 machine learning이 아니라고 본 것(s-d70721 — 원문은 체스 규칙이 프로그래머가 미리 준다고만 한다). knowledge base 행(s-876209)은 Goodfellow 그림 1.4의 예를 따랐다
- 그림 1.5에 기댄 표(s-fc7afb·s-c6ff5a·s-dad330·s-bbbbf4)와 s-6e5a45·s-8391b0: 어느 칸이 데이터에서 배우는지는 그림의 음영으로만 표시되고 본문 텍스트로는 확인되지 않는다 — 그림을 직접 보고 대조해야 한다
- 비유와 번역어: representation(표현)을 「모델이 입력을 나타내는 방식, 곧 배운 feature들」로 풀이(s-06ef4e — 원문은 representation에 든 정보 하나하나를 feature라 한다), 「소프트웨어로 말하면 모델은 함수」(s-363a1e), 「사람이 설계하는 일의 중심이 feature에서 모델 구조와 학습 과정으로 옮겨 갔다」(s-472bf6), 「AI는 특정 기술이 아니라 목표에 붙은 이름」(s-5bb873 — McCarthy 제안서의 연구 목표에서 끌어낸 정리)
