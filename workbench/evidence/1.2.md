## 교차 검토 우선 목록
- 여섯 축(분야·구조·과제·방식·학습·규모와 활용)이라는 분류 자체와 이름마다의 축 배정(§1 표, §2 각 절의 「~는 구조 이름이 아니다」, §3, 헷갈리기 쉬운 점, 정리, 확인 문제 답)은 책 고유의 분류다. 출처가 없고 설명 갈래로 두었다
- s-81b034: 「Bidirectional」을 학습 방식으로 배정한 판단. Devlin2019는 왼쪽·오른쪽 문맥을 함께 조건으로 하는 사전학습 표현이라 말하고, Google 용어집 BERT 항목은 encoder 사용과 'Is bidirectional'을 따로 적는다
- s-2ae8cd·s-cbc8c2: ViT 전체를 구조 이름으로 본 판단과 CLIP 이름 조각(Contrastive=학습 신호, Language-Image=분야, Pre-training=학습 단계)의 축 배정
- s-34b436·s-945c35·s-419114: DETR(Carion2020)는 CNN backbone과 Transformer encoder-decoder를 함께 쓴다. 「Transformer로 만든 detector」「CNN으로도 Transformer로도 만든다」가 단순화인지 볼 곳
- 교과 판정 가운데 일반 용어집(Google2026)과 Hugging Face 목록 이름에 기댄 곳: 분야 표의 CV·speech 행(s-c50e63·s-9f6c1d), image classification의 출력(s-1db773·s-d8e0b7·s-910b3e), bounding box를 box로 줄여 부른다(s-ed5c2c), object detection의 confidence score(s-bccb7e는 DETR 본문의 'corresponding confidence'에 기댐)
- 번역어와 풀이: RLHF를 책은 reinforcement learning from human feedback으로 풀었고 Meta2024 카드는 'reinforcement learning with human feedback'이라 적는다. modality(모달리티)·semantic segmentation(의미론적 분할)·panoptic segmentation(파놉틱 분할) 등 번역어
- s-e2845a: Zhao2023 v19의 두 서술('tens or hundreds of billions', 'hundreds of billions (or more)')을 「수백억~수천억」으로 합친 것. 장을 쓸 때 본 판과 대장이 받은 판(v19)이 같은지 모른다
- s-4709a1·s-d8e509: 「LLM·VLM·foundation model의 경계가 문헌마다 다르다」는 책이 문헌을 견준 종합이다(foundation model은 Bommasani2021 정의와 Google 용어집 정의를 견줌; VLM은 Hugging Face와 Bordes2024를 견줌)
- s-ccd743: 「2021년 Stanford 대학의 연구 보고서」 — 연도는 arXiv v1 날짜(2021-08-16), 기관은 v1 표지의 CRFM — Stanford University에 기댐
- s-f7c130: diffusion 설명 — Ho2020은 Markov chain과 Gaussian noise로 말하며, 「noise를 조금씩 걷어 내며 이미지를 완성한다」는 reverse process(샘플링)를 풀어 쓴 것이다
- s-cb3dda·s-862fdf: VLM의 범위 — Bordes2024 초록은 VLM을 '이미지를 언어에 잇는' 모델로 다루고 생성 모델까지 갈래에 넣는다. 「함께 다루는 모델」이라는 정의가 맞는지
- s-2e2269: VAE 행은 Kingma2013의 probabilistic encoder·prior·KL 항을 「값마다 나올 확률」「미리 정해 둔 확률에 가깝도록」으로 풀었다. prior가 parameter 없이 정해진 것은 논문 §3의 예이고, §2의 일반 설정에서는 prior도 parameter를 가질 수 있다
- s-9d1947: GAN 행의 「neural network 둘」은 Goodfellow2014가 다룬 adversarial nets(둘 다 multilayer perceptron)의 설정이다. 원 논문의 틀(framework)은 G와 D를 임의의 함수로 둔다
- s-56009b·s-5ef093: SFT의 일반 뜻과 「instruction tuning이라고도 부른다」는 Zhao2023(LLM 조사 논문) 한 곳의 서술이다. Meta2024는 SFT와 RLHF를 거친 판을 instruction tuned라 부른다(s-82b838)

## 미확인으로 보낸 것
- 모델 이름을 붙이는 공식 분류 체계가 없다는 것을 직접 밝힌 문헌(한눈에·§4·정리에서 뺌)
- ISO/IEC 22989 원문의 범위 조항과, 이 표준이 모델 이름 짓기 규칙을 다루지 않는다는 것(www.iso.org 403으로 원문을 받지 못함)
- 구조 이름(CNN·RNN·Transformer)과 task 이름(classification·detection·segmentation)이 교과서와 논문에서 거의 같은 뜻으로 쓰인다는 것
- 모델 이름 꼬리(Instruct·Base)와 크기 표기(8B)가 공개 모델 저장소의 관례이고 정해진 규칙은 없다는 것(여러 계열의 모델 카드 비교 필요)
