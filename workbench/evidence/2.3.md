## 교차 검토 우선 목록
- 설명으로 둔 정의: N(0, I)를 「성분마다 standard normal에서 따로 뽑아 채운 vector의 distribution」이라 한 문장(§3)은 대장 사실이 아니다. f39는 isotropic Gaussian(covariance = scalar × identity)까지만 받친다. 성분 독립과 같다는 설명이 교과 정의와 어긋나지 않는지
- 교과 판정: likelihood를 「관측한 데이터를 고정하고 parameter의 함수로 본 확률」로 정의한 문장(§7.1)은 f46(MLE가 최대로 하는 확률의 곱)으로만 받쳤다. 정의 문장을 직접 쓴 출처는 대장에 없다
- 계산 갈래로 받친 교과 내용: Var(aX) = a²Var(X)의 유도, 곱 q_i k_i의 variance = 1(독립인 두 변수 곱의 expectation = expectation의 곱을 썼다), exp·log의 성질 표(e^x > 0, 단조 증가, log 1 = 0, 1보다 작은 양수의 log가 음수)는 runs/calc-1.txt와 code-d.txt로만 받쳤다(조사 gaps 1·2)
- 출처 범위: Guo2017의 과신 결과(§9.2)는 CIFAR-100의 LeNet 대 ResNet, 저자들의 vision·NLP dataset, 2017년 시점 모델 조건을 본문에 달았다. 「깊은 neural network가 높은 confidence를 내는 경향」(확인 문제 5 답)이 측정 조건을 넘어 일반화되지 않았는지
- 책 고유의 정리: §5의 스팸 2×2 표와 「I like cats」 확률(0.2·0.1·0.05)은 지어낸 예시 숫자다. 예시라는 것이 문장에서 드러나는지
- 표준과 관례 상자의 logit 세 쓰임: 「이 책은 뒤의 두 뜻을 logit이라 부른다」는 책의 선택이다(f55·f58·f59)
- 번역어: sampling(샘플링), standard error(표준 오차), data-generating distribution(데이터 생성 분포), expected calibration error(ECE, 기대 보정 오차), discrete·continuous random variable(이산·연속 확률 변수). derivative(도함수)는 같은 묶음 2.2의 용어집 행과 맞춰야 한다
- 설명: §1의 「cat 0.6, dog 0.4를 내는 모델이 얼마나 확신하는지까지 알려 준다」, §4.4의 「layer 하나도 같은 셈으로 출력 크기를 어림할 수 있다」, §4.5의 seed 여러 개의 평균±standard deviation 한 줄(조사 gaps: 직접 받치는 출처 없음)
