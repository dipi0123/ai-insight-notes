## 교차 검토 우선 목록
- 교과 판정(유도로 받친 곳): §1에서 self-information의 세 성질이 2.3 §6의 log 성질에서 바로 나온다는 설명, §4의 H(p,q) ≥ H(p)와 등호 조건(f17·f26), §5.1의 one-hot일 때 H(p)=0·CE=KL=−log q_y(조사 gaps 2·3대로 f23·f29와 runs/code-c.txt로 받쳤다)
- 설명으로 둔 정의: §5.2의 empirical distribution을 「training set에서 예제 하나를 무작위로 고를 때의 distribution」이라 한 문장. Goodfellow §5.5는 「training set이 정하는 empirical distribution」까지만 말한다
- §5.1의 「수학적으로는 softmax 확률이 정확히 0이나 1이 되지 않는다」: float에서는 underflow로 1.0이 나올 수 있다는 것은 적지 않았다(2.3 §8.3이 underflow를 다룬다). f41(Goodfellow)이 같은 취지
- §5.2 끝의 「language model도 token마다 같은 loss를 쓴다」와 「language modeling 목표를 부호만 바꾼 것이 token마다의 cross-entropy의 합」은 2.3 §7.3(Radford2018 식)에서 이은 설명이다. 2.4 대장에는 language model의 loss를 직접 받치는 사실이 없다
- §6 perplexity 행: 정의 식을 넣지 않고(조사 gaps 1) 「perplexity라는 지표로 language model을 평가한다」만 설명 갈래로 두었다
- 비유와 번역어: 장 전체를 「놀람」 비유로 이었다(self-information = 놀람, entropy = 평균 놀람, CE = q로 놀란 평균, KL = 더 생긴 놀람). 번역어 self-information(자기 정보량), empirical distribution(경험 분포), binary cross-entropy(이진 교차 엔트로피), relative entropy(번역어 없이 KL의 다른 이름), bit·nat(한국어 없음)
- 책 고유의 선택: 표준과 관례 상자의 「이 책에서 cross-entropy loss라고 하면 분류의 좁은 뜻」, 헷갈리기 쉬운 점의 「이 책의 loss 값은 모두 nat」, §4 끝의 「§5의 학습은 데이터 distribution을 앞에, §6의 RLHF는 학습 중인 모델을 앞에 둔다」(f30·f49로 받침)
- 옮긴 표현: RLHF 행에서 Ouyang §3.5의 over-optimization을 「reward model에 과하게 맞추는 것」으로 옮겼다. distillation 행의 「작은 모델」은 Hinton의 distilled model
