# 작업대

책에 반영하기 전의 재료를 잠시 두는 곳이다. 정본이 아니다. 여기 있는 글을 근거로 삼지 말고, 책에 반영할 때 사실을 다시 확인한다([작업 절차 §5](../editorial/workflow.md#5-웹-채팅다른-세션-결과-들여오기)).

| 폴더 | 담는 것 | 지우는 때 |
|---|---|---|
| `inbox/` | 웹 채팅의 반영 블록, 다른 프로젝트 세션에서 나온 설명 | 책에 반영한 뒤 |
| `drafts/` | 한 번에 반영하기 큰 초안(장 전체 재구성 등) | 책에 옮긴 뒤 |
| `reviews/` | 교차 검토 결과 | 지적을 처리하고 장 상태를 검토완료로 바꾼 뒤 |

- inbox·drafts 파일 이름: `YYYY-MM-DD_<ai>_<주제>.md` (예: `2026-11-25_grok_f1-score.md`)
- 검토 파일 이름: `<장번호>_<검토AI>.md` (예: `3.7_gemini.md`)
- `inbox/`의 파일은 git에 올리지 않는다(`.gitignore`). 저장소가 공개라서, 다른 프로젝트 세션의 원문이 섞일 수 있기 때문이다. drafts·reviews는 git에 올라가고, 지운 파일은 git 이력에 남는다.
- 여기에 오래 쌓아 두지 않는다.
